This tab shows how real GPU kernels behave when AMD’s sanitizers run over them: waitcheck (a static s_waitcnt wait-count hazard scan of the code object) and ConSan (a dynamic data-race / concurrency check at run time). Where both produced a report, the kernel is shown under each; when a scan was skipped or its report is missing (e.g. a non-GPU run), only the sanitizer(s) that actually ran appear.

No expected-behavior comparison on this tab — it is observed-only and does not gate the nightly. An error, fail, or warn here records how the kernel behaved under the sanitizer; it is never a regression. Each case lists the recipe that produced it and a copy-paste command to reproduce the run yourself.
